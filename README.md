# 💖 Chúc mừng 20/10/2025 – Phương Nhung

Đây là một **website nhỏ được mình tạo ra để chúc mừng ngày Phụ nữ Việt Nam 20/10/2025** dành cho **Phương Nhung**.

Website được xây dựng bằng **HTML, CSS và JavaScript**, với mục đích gửi lời chúc, tạo một kỷ niệm đẹp và lưu lại trên GitHub như một **mini project cá nhân**.

---

# 🌸 Nội dung website

Website bao gồm các nội dung chính:

* Lời chúc mừng ngày **20/10**
* Trang web thiết kế đơn giản, dễ thương
* Hiệu ứng tương tác bằng JavaScript
* Thông điệp ý nghĩa dành cho Phương Nhung

---

# ▶️ Cách chạy website

Mở file:

```id="p2e3bf"

```

bằng trình duyệt:

* Microsoft Edge
* Firefox

### Cách 2 (khuyến khích)

Nếu dùng **VS Code**:

1. Cài extension **Live Server**
2. Chuột phải vào `index.html`
3. Chọn:

```id="j7md8p"
Open with Live Server
```
