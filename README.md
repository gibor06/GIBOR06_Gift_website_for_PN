# 💖 Chúc mừng 20/10/2025 – Phương Nhung

**Chúc mừng 20/10/2025 – Phương Nhung** là một **website nhỏ mang tính cá nhân** được tạo ra nhằm gửi lời chúc mừng nhân ngày **Phụ nữ Việt Nam 20/10/2025** đến **Phương Nhung**.

Website được xây dựng bằng **HTML, CSS và JavaScript**, với mục đích tạo nên một món quà tinh thần đơn giản nhưng ý nghĩa, đồng thời lưu giữ lại như một **mini project cá nhân** trên GitHub.

Project này không chỉ mang ý nghĩa kỷ niệm mà còn là cơ hội để luyện tập thêm về:

* **HTML cơ bản**
* **CSS giao diện**
* **JavaScript tương tác**
* **Xây dựng website tĩnh cá nhân**

Dự án phù hợp với những ai đang muốn thực hành tạo một trang web nhỏ mang tính cảm xúc, cá nhân hóa và dễ triển khai.

# ▶️ Cách chạy website

Đây là **website tĩnh**, không yêu cầu cài đặt backend hoặc cấu hình server.

## 1️⃣ Cách 1 — Mở trực tiếp bằng trình duyệt

Mở file:

```text
index.html
```

bằng một trong các trình duyệt sau:

* Google Chrome
* Microsoft Edge
* Firefox

---

## 2️⃣ Cách 2 — Chạy bằng Live Server trong VS Code

Nếu bạn sử dụng **Visual Studio Code**, có thể chạy project thuận tiện hơn với **Live Server**:

1. Cài extension **Live Server**
2. Chuột phải vào file `index.html`
3. Chọn:

```text
Open with Live Server
```

Cách này giúp website được mở nhanh hơn và dễ kiểm tra khi chỉnh sửa giao diện.
